# Radar_Imobiliario_Documento_4_Due_Diligence_v1.0

Radar Imobiliário
Documento 4 — Processo de Análise Profunda e Due Diligence | v1.0
Documento de negócio — critérios, evidências, decisões e checklist.
Princípio: o Radar encontra a oportunidade; a Due Diligence decide se a oportunidade é real.

# 1. Objetivo

Definir o processo de investigação após uma propriedade receber classificação relevante no Radar. A finalidade é transformar uma oportunidade potencial em decisão fundamentada, identificando fatos que confirmem, reduzam ou destruam a tese econômica.
- Confirmar identidade e características do imóvel.
- Validar matrícula e situação documental.
- Investigar ocupação e posse.
- Investigar débitos e obrigações.
- Investigar processos e restrições.
- Validar mercado, aluguel e liquidez.
- Estimar reforma e custos extraordinários.
- Simular cenários conservador, base e estressado.
- Definir aprovação, reprovação ou monitoramento.

# 2. Jornada da análise


| Etapa | Objetivo | Profundidade |
|---|---|---|
| Radar | descobrir | baixa |
| Pré-análise | confirmar tese básica | média |
| Due Diligence | validar riscos/economia | alta |
| Decisão | aprovar/reprovar | máxima |
| Pós-decisão | acompanhar resultado | contínua |

A profundidade deve ser proporcional ao score, valor, risco, estratégia e custo de investigação.

# 3. Status


| Status | Significado |
|---|---|
| Capturado | encontrado pela fonte |
| Qualificado | passou filtros iniciais |
| Em análise | investigação iniciada |
| Pendente | há informação faltante |
| Aprovado | tese validada |
| Reprovado | tese destruída ou risco incompatível |
| Monitorando | ainda não é hora de decidir |
| Adquirido | investimento realizado |


# 4. Fato → evidência → interpretação

A análise deve separar o que foi encontrado, qual evidência comprova e qual conclusão foi tirada.

| Elemento | Exemplo |
|---|---|
| Fato | há débito condominial informado |
| Evidência | documento/consulta |
| Interpretação | pode alterar o custo total |
| Impacto | reduzir margem |
| Decisão | continuar se responsabilidade for confirmada |


# 5. Identificação do imóvel

- Endereço completo.
- Matrícula(s), cartório e comarca.
- Identificador da fonte.
- Condomínio, bloco, torre, unidade e vaga.
- Áreas privativa, comum e total.
- Quartos, banheiros e vagas.
- Tipo de imóvel.
- Situação de ocupação.
- Origem e data da captura.
Divergências relevantes entre fontes devem gerar alerta de inconsistência.

# 6. Matrícula e titularidade


| Verificação | Resultado esperado | Impacto |
|---|---|---|
| Matrícula localizada | sim | baixo |
| Titularidade | coerente | baixo |
| Descrição física | coerente | médio |
| Ônus | identificados | médio/alto |
| Penhoras/restrições | identificadas | alto |
| Indisponibilidade | não impeditiva | crítico se impeditiva |
| Averbações | analisadas | variável |
| Vagas/área | compatíveis | médio/alto |

A matrícula é fonte central, mas não substitui a investigação de outras obrigações e fatos externos.

# 7. Ocupação e posse

- Identificar ocupado/desocupado.
- Identificar tipo de ocupação conhecido.
- Verificar locação informada.
- Estimar complexidade e prazo de desocupação quando aplicável.
- Considerar risco de posse na margem e no prazo.
- Não presumir desocupação sem evidência.

# 8. Condomínio


| Item | Pergunta |
|---|---|
| Valor mensal | qual o valor atual? |
| Extraordinárias | existem cobranças? |
| Atrasos | há débitos conhecidos? |
| Processos | há litígios relevantes? |
| Obras | há obras previstas? |
| Perfil | há indícios de condomínio problemático? |
| Impacto | prejudica aluguel/revenda? |

Condomínio entra no custo e no cenário de carregamento.

# 9. IPTU e tributos

- Verificar situação cadastral quando possível.
- Identificar débitos conhecidos.
- Separar tributo corrente de dívida histórica.
- Determinar responsabilidade conforme documentos e regras aplicáveis.
- Adicionar valores confirmados/estimados ao custo quando economicamente atribuíveis.
- Registrar incerteza; ausência de informação não é valor zero.

# 10. Jurídico

- Processos relacionados ao imóvel.
- Processos do devedor/proprietário quando pertinentes.
- Execuções, penhoras e indisponibilidades.
- Ações possessórias.
- Questões condominiais ou tributárias.
- Suspensões, embargos ou questionamentos da venda.
- Restrições registrárias.
- Classificar relevância, impacto e necessidade de análise especializada.
A existência de processo não torna automaticamente o imóvel inviável; o impacto precisa ser entendido.

# 11. Origem da oportunidade


| Verificação | Pergunta |
|---|---|
| Fonte | de onde veio? |
| Modalidade | venda direta, leilão, oferta etc.? |
| Fase | qual fase/praça? |
| Preço | qual preço vigente? |
| Avaliação | qual referência? |
| Comissão | há comissão? |
| Condições | quais condições relevantes? |
| Financiamento | é possível? |
| Prazo | quando ocorre pagamento/transferência? |
| Alterações | mudou desde a captura? |


# 12. Dívidas e responsabilidades


| Situação | Tratamento |
|---|---|
| Confirmada | usar no custo |
| Estimada | usar cenário + margem |
| Possível não quantificada | reduzir confiança + contingência |
| Desconhecida | não assumir zero |
| Responsabilidade indefinida | bloquear decisão final até esclarecer |


# 13. Estado físico e reforma


| Nível | Descrição | Impacto |
|---|---|---|
| 0 | Pronto | baixo |
| 1 | Cosmética | baixo |
| 2 | Moderada | médio |
| 3 | Alta | alto |
| 4 | Crítica | muito alto |

- Estimar por ambiente quando possível.
- Separar reforma necessária de desejável.
- Adicionar contingência.
- Para flip, medir reforma contra venda e prazo.
- Para renda, priorizar o mínimo necessário para locação.

# 14. Visita

- Estado real.
- Umidade/infiltração.
- Instalações elétrica e hidráulica.
- Esquadrias.
- Pisos/revestimentos.
- Telhado/cobertura em imóveis horizontais.
- Elevadores e áreas comuns.
- Vizinhança imediata.
- Ruído e características da rua.
- Vagas e acesso.
- Fotos e evidências datadas.
Visita não precisa ser obrigatória em toda oportunidade, mas deve ser requisito para níveis de decisão definidos por estratégia e risco.

# 15. Validação do mercado

- Confirmar comparáveis do valuation.
- Priorizar mesmo condomínio quando possível.
- Separar anúncio de transação efetiva.
- Eliminar outliers.
- Ajustar padrão, estado e características.
- Validar preço/m² no segmento correto.
- Reavaliar dados antigos.
- Gerar faixas conservadora, base e otimista.

# 16. Validação do aluguel


| Indicador | Verificação |
|---|---|
| Aluguel anunciado | comparar ofertas atuais |
| Aluguel provável | estimar valor realista |
| Condomínio | considerar impacto |
| IPTU | considerar responsabilidade |
| Vacância | estimar |
| Liquidez | tempo provável de locação |
| Yield | recalcular sobre custo total |

Não usar o maior anúncio encontrado apenas para fabricar um yield.

# 17. Cenários econômicos


| Cenário | Premissa |
|---|---|
| Otimista | mercado favorável e execução eficiente |
| Base | premissas mais prováveis |
| Conservador | receita menor + custos maiores |
| Estressado | baixa receita + maior custo + maior prazo |

A oportunidade deve sobreviver ao cenário mínimo exigido pela estratégia. O estressado mede a proteção existente.

# 18. Renda — checklist

- Yield sobre custo econômico total.
- Aluguel conservador.
- Vacância.
- Condomínio e IPTU.
- Manutenção.
- Liquidez de locação.
- Perfil de demanda.
- Margem de segurança.
- Risco de inadimplência conforme parâmetros.
Pergunta: este imóvel gera renda adequada ao risco e ao capital imobilizado?

# 19. Revenda / Flip — checklist

- Preço de entrada.
- Venda conservadora.
- Reforma.
- Custos de aquisição.
- Carregamento.
- Custos de venda.
- Prazo de saída.
- Desconto para venda rápida.
- Margem líquida.
- Retorno sobre capital.
Pergunta: se eu precisar vender abaixo do preço ideal, ainda ganho dinheiro?

# 20. Valorização — checklist

- Localização.
- Oferta futura.
- Demanda.
- Infraestrutura.
- Transformações urbanas relevantes.
- Preço/m².
- Potencial de melhoria do entorno.
- Horizonte.
- Cenário sem valorização.
A tese deve ser conhecida mesmo sem contar com valorização futura.

# 21. MCMV / baixa renda

- Ticket compatível com demanda.
- Liquidez de venda e aluguel.
- Preço/m².
- Financiabilidade.
- Condomínio.
- Infraestrutura.
- Localização dentro dos parâmetros definidos.
- Demanda efetiva.
Mercado popular é segmento econômico, não sinônimo de baixa qualidade.

# 22. Terreno

- Zoneamento e uso permitido.
- Potencial construtivo.
- Testada.
- Profundidade/formato.
- Topografia.
- Infraestrutura.
- Restrições ambientais quando aplicáveis.
- Preço/m².
- Demanda e liquidez.

# 23. Casa / sobrado

- Terreno.
- Área construída.
- Estado físico.
- Garagem.
- Regularização.
- Reforma.
- Liquidez da rua.
- Comparáveis do mesmo padrão.
- Potencial de ampliação quando pertinente.

# 24. Apartamento

- Condomínio.
- Vaga.
- Andar.
- Elevador.
- Posição.
- Área privativa.
- Estado.
- Planta.
- Aluguel.
- Liquidez.
- Comparáveis no próprio condomínio.

# 25. Checklist de decisão


| Dimensão | Status | Mínimo |
|---|---|---|
| Identificação | OK/pendente/divergente | OK |
| Matrícula | OK/risco | OK |
| Ocupação | conhecida/desconhecida/risco | conhecida ou risco precificado |
| Condomínio | OK/pendente/risco | risco conhecido |
| Tributos | OK/pendente/risco | risco conhecido |
| Jurídico | baixo/médio/alto/crítico | sem crítico |
| Mercado | forte/médio/fraco | evidência mínima |
| Reforma | baixa/média/alta | custo estimado |
| Liquidez | alta/média/baixa | mínimo da estratégia |
| Economia | positiva/marginal/negativa | positiva |
| Confiança | alta/média/baixa | mínimo |
| Estratégia | aderente/parcial/não | aderente |


# 26. Critérios de reprovação

- Risco crítico incompatível.
- Margem negativa no cenário mínimo.
- Impossibilidade de validar condição essencial.
- Liquidez abaixo do mínimo sem compensação.
- Dados contraditórios que impedem identificar o ativo.
- Restrição documental/jurídica impeditiva.
- Economia dependente apenas do cenário otimista.
- Custos desconhecidos capazes de destruir a margem.

# 27. Aprovação condicionada

Quando a tese é boa, mas existe pendência, usar 'Aprovado com condição'. A condição precisa ser objetiva.

| Condição | Liberação |
|---|---|
| Documento | após matrícula/documento atualizado |
| Dívida | após confirmar valor/responsabilidade |
| Visita | após confirmar estado |
| Preço | se cair até limite |
| Margem | se custo final ficar abaixo do teto |
| Jurídico | após validação da questão |


# 28. Decisão final


| Decisão | Quando usar |
|---|---|
| COMPRAR | tese validada e risco aceitável |
| COMPRAR SE | condição objetiva pendente |
| MONITORAR | tese boa, mas timing/preço/dados insuficientes |
| NÃO COMPRAR | economia fraca |
| BLOQUEAR | risco/restrição incompatível |


# 29. Explicação final obrigatória

- Preço de aquisição.
- Custo econômico total.
- Valor de mercado conservador/base.
- Desconto líquido.
- Margem.
- Yield, quando aplicável.
- Liquidez.
- Risco.
- Confiança.
- Evidências.
- Pendências.
- Principais riscos.
- Melhor estratégia.
- Decisão recomendada.
- Condições para aprovação.

# 30. Registro das evidências

- Registrar origem.
- Registrar data da consulta.
- Registrar valor encontrado.
- Registrar evidência.
- Registrar interpretação.
- Registrar impacto econômico.
- Registrar pendência.
- Preservar histórico da conclusão.

# 31. Reavaliação

- Queda de preço → recalcular.
- Novo documento → reavaliar risco.
- Novo débito → atualizar custo.
- Novo comparável → atualizar valuation.
- Mudança de ocupação → atualizar liquidez/prazo.
- Mudança de estratégia → recalcular score.
- Mudança de parâmetros → reprocessar conforme vigência.

# 32. Princípios de prudência

- Não preencher lacunas com otimismo.
- Ausência de informação não significa ausência de risco.
- Não usar valuation alto artificialmente.
- Não usar aluguel máximo para fabricar yield.
- Não ignorar pequenos custos acumulados.
- Não confundir oportunidade com urgência.
- Score alto nunca mascara risco crítico.
- Sempre saber o que ainda não sabemos.

# 33. Relação entre os quatro documentos


| Documento | Papel |
|---|---|
| 1 — Manual de Regras | como o Radar pensa |
| 2 — Valuation e Mercado | como estima valor |
| 3 — Estratégias e Score | como prioriza |
| 4 — Due Diligence | como confirma ou destrói a tese |

A cadeia de negócio fica: Descobrir → Qualificar → Valorar → Pontuar → Investigar → Decidir → Monitorar → Aprender.
