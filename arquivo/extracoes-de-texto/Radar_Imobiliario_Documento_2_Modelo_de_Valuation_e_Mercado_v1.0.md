# Radar_Imobiliario_Documento_2_Modelo_de_Valuation_e_Mercado_v1.0

💰 DOCUMENTO 2 — MODELO DE VALUATION E MERCADO
Como o Radar estima quanto um imóvel realmente vale
Documento de negócio • Sem dependência tecnológica • Versão 1.0

# 1. Objetivo

Definir o processo de negócio para estimar o valor econômico provável de um imóvel, determinar o intervalo razoável de mercado,
medir a confiança da estimativa e utilizar esse resultado para identificar descontos reais. O valuation é a principal referência do
Radar para diferenciar uma oferta aparentemente barata de uma oportunidade econômica verdadeira.

# 2. Princípio fundamental

O valor da Caixa é uma referência. O mercado é a referência econômica principal.
O valor informado pela fonte pode estar acima ou abaixo do mercado. Portanto, o Radar deve manter separadamente:
valor da fonte, valor observado nos comparáveis, valor estimado pelo Radar, faixa de incerteza e nível de confiança.

# 3. O que o valuation precisa responder

- Qual seria o valor provável do imóvel em uma negociação normal?
- Quais imóveis sustentam essa conclusão?
- Quão semelhantes são esses imóveis?
- Qual preço/m² é observado?
- Quais ajustes são necessários?
- Existem outliers?
- Como o tempo alterou os preços?
- Existe informação suficiente?
- Qual é a faixa conservadora, base e otimista?
- Qual é a confiança da estimativa?

# 4. Hierarquia de evidências


| Prioridade | Evidência | Peso conceitual |
|---|---|---|
| 1 | Mesmo condomínio, mesma tipologia e características muito semelhantes | Muito alto |
| 2 | Mesmo condomínio, diferenças ajustáveis | Alto |
| 3 | Mesma microregião, imóvel muito semelhante | Alto |
| 4 | Mesmo bairro, características semelhantes | Médio/alto |
| 5 | Bairros/regiões próximas comparáveis | Médio |
| 6 | Mercado mais amplo/modelo estatístico | Baixo/médio quando necessário |

Quanto mais distante ou diferente o comparável, maior a necessidade de ajuste e menor a confiança.

# 5. Unidade básica de comparação

O Radar deve evitar comparar apenas preço total. A unidade de comparação normalmente será preço por m², complementada por
características do imóvel. O preço/m² sozinho também não é suficiente: dois imóveis com o mesmo preço/m² podem possuir valores
muito diferentes devido a localização, padrão, vagas, condomínio, idade e estado.

# 7. Localização — ajuste de valor

A localização deve ser analisada em diferentes níveis.

| Nível | Exemplo | Tratamento |
|---|---|---|
| Cidade | Curitiba | Contexto macro |
| Bairro | Xaxim | Referência principal |
| Microregião | 500m–1km | Ajuste relevante |
| Condomínio | mesmo residencial | Evidência prioritária |
| Entorno | comércio/transporte/serviços | Ajuste contextual |
| Rua/micro-localização | posição específica | Ajuste fino |


# 8. Comparáveis — requisitos mínimos

Um comparável deve ser utilizado somente quando houver justificativa de similaridade.

| Critério | Pergunta |
|---|---|
| Tipo | É o mesmo tipo de imóvel? |
| Localização | Está suficientemente próximo? |
| Área | A diferença de área é aceitável? |
| Quartos | Tem composição semelhante? |
| Vagas | Tem quantidade comparável? |
| Padrão | Possui padrão semelhante? |
| Estado | Conservação semelhante? |
| Idade | Idade comparável? |
| Condomínio | Custos/estrutura comparáveis? |
| Atualidade | Preço ainda representa o mercado atual? |


# 9. Qualidade do comparável


| Classe | Descrição |
|---|---|
| A | Quase equivalente ao imóvel avaliado. |
| B | Muito semelhante, com diferenças ajustáveis. |
| C | Semelhante, mas com diferenças relevantes. |
| D | Referência fraca; utilizar somente se necessário. |
| E | Não utilizar. |


# 10. Quantidade de comparáveis

Quantidade não substitui qualidade.

| Situação | Interpretação |
|---|---|
| 1–2 comparáveis fortes | Pode indicar faixa, mas confiança limitada. |
| 3–5 bons comparáveis | Base inicial razoável. |
| 6–10 bons comparáveis | Base consistente. |
| 10+ bons comparáveis | Boa sustentação, desde que não sejam redundantes. |
| Muitos comparáveis fracos | Não significa alta confiança. |


# 11. Diversidade dos comparáveis

O Radar deve evitar uma amostra artificialmente concentrada. Quando possível, combinar comparáveis do mesmo condomínio com referências externas ajuda a validar se o preço interno é coerente com o mercado.

# 12. Preço anunciado x preço de negociação

Preço anunciado pode conter margem de negociação. Quando o Radar possuir evidência de preço efetivamente transacionado, essa
informação deve receber maior peso. Quando só houver preço anunciado, o sistema deve registrar explicitamente essa limitação.

| Evidência | Força |
|---|---|
| Transação observada | Muito alta |
| Preço efetivamente negociado conhecido | Muito alta |
| Oferta recente comparável | Alta |
| Anúncio antigo | Média/baixa |
| Preço sem data confiável | Baixa |


# 13. Temporalidade

Um comparável de dois anos atrás não deve ser tratado como equivalente a um comparável atual sem ajuste.

| Idade do dado | Tratamento conceitual |
|---|---|
| Muito recente | Peso máximo |
| Recente | Peso alto |
| Moderado | Peso reduzido |
| Antigo | Ajustar ou reduzir fortemente o peso |
| Muito antigo | Excluir salvo ausência de mercado melhor |


# 14. Ajuste temporal

Quando houver evidência de mudança do mercado, o preço histórico deve ser ajustado para uma referência atual. O ajuste deve ser
baseado em comportamento observado na região/tipologia, e não em uma suposição genérica de valorização.
Exemplo conceitual: comparável histórico de R$ 280 mil → indicador de mercado acumulou +8% → referência ajustada ≈ R$ 302,4 mil.

# 15. Ajustes por área

Imóveis menores podem apresentar preço/m² diferente de imóveis maiores. O Radar não deve assumir linearidade perfeita entre área
e preço. O ajuste deve ser calibrado por segmento.
Regra: comparar preferencialmente imóveis dentro de uma faixa de área semelhante e usar ajustes apenas quando houver evidência suficiente.

# 16. Ajuste por quartos

Quartos alteram o público consumidor e podem alterar preço/m². Comparar 1 quarto com 3 quartos diretamente reduz a qualidade da avaliação.

| Situação | Tratamento |
|---|---|
| Mesmo número de quartos | Melhor comparável |
| Diferença de 1 quarto | Usar somente com ajuste/evidência |
| Diferença grande | Preferir outro comparável |
| Mercado especializado | Avaliar por estratégia e demanda |


# 17. Ajuste por vagas

Vagas podem possuir impacto relevante e diferente por região. O ajuste deve ser baseado em comparáveis locais.
- 1 vaga vs 2 vagas
- vaga coberta vs descoberta
- vaga livre vs presa
- ausência de vaga
- características de acesso

# 18. Ajuste por padrão


| Padrão | Exemplos |
|---|---|
| Econômico | Acabamento simples, público de entrada |
| Médio | Padrão intermediário |
| Superior | Acabamento/infraestrutura superiores |
| Alto padrão | Características premium |
| Luxo | Mercado muito específico |

Imóveis de padrões diferentes não devem ser misturados sem forte justificativa.

# 19. Ajuste por estado de conservação


| Estado | Impacto no valuation |
|---|---|
| Novo/pronto | Referência positiva |
| Bom | Pequeno ajuste |
| Regular | Ajuste moderado |
| Reforma leve | Redução correspondente |
| Reforma média | Redução relevante |
| Reforma pesada | Grande ajuste |
| Estado incerto | Reduz confiança e exige reserva |


# 20. Condomínio

Condomínio é simultaneamente um componente de valor e de atratividade. Um condomínio elevado pode reduzir a capacidade de aluguel
e o universo de compradores, enquanto uma estrutura excelente pode aumentar a atratividade.
- valor mensal
- taxas extraordinárias
- estrutura
- idade
- manutenção
- inadimplência quando disponível
- obras previstas
- qualidade das áreas comuns

# 21. Imóveis no mesmo condomínio

Quando existirem diversos comparáveis no mesmo condomínio, eles devem receber prioridade. Porém, o Radar deve verificar se o
condomínio possui distorção própria. Se todas as unidades estiverem superavaliadas, comparar apenas internamente perpetua o erro.

# 22. Outliers

Preços extremos não devem ser incorporados automaticamente.

| Outlier | Ação |
|---|---|
| Muito acima do padrão | Investigar motivo; excluir se inexplicado. |
| Muito abaixo do padrão | Investigar urgência, defeito ou condição especial. |
| Anúncio duplicado | Deduplicar. |
| Imóvel claramente diferente | Excluir. |
| Oferta excepcional comprovada | Pode ser usada como evidência de piso, com cautela. |


# 23. Mediana x média

Como princípio de negócio, a mediana é frequentemente mais resistente a outliers do que a média. O Radar deve comparar as duas e
usar a medida mais robusta para o contexto. A escolha definitiva será calibrada por tipo de mercado.

| Situação | Preferência |
|---|---|
| Muitos outliers | Mediana |
| Mercado homogêneo | Média e mediana podem convergir |
| Poucos dados | Faixa + análise qualitativa |
| Mercado muito heterogêneo | Segmentar antes de calcular |


# 24. Segmentação do mercado

Antes de calcular valor, o Radar deve perguntar se está misturando mercados diferentes.
- novo x usado
- econômico x alto padrão
- 1 x 3 quartos
- com x sem vaga
- mesmo x outro condomínio
- reformado x original
- residencial x comercial

# 25. Preço/m²

Preço/m² = preço ÷ área considerada
A área utilizada deve ser explicitada. Área útil, construída e total não são equivalentes.

# 26. Área correta para comparação


| Tipo | Referência preferencial |
|---|---|
| Apartamento | Área útil, quando comparável |
| Casa | Área construída + terreno separadamente quando necessário |
| Sobrado | Área construída + terreno |
| Terreno | Área do terreno |
| Comercial | Área privativa/locável conforme mercado |

Nunca misturar áreas diferentes sem ajuste.

# 27. Valuation por faixa

O Radar deve evitar falsa precisão.

| Faixa | Exemplo |
|---|---|
| Piso conservador | R$ 295.000 |
| Valor base | R$ 315.000 |
| Teto razoável | R$ 335.000 |

A faixa deve refletir dispersão dos comparáveis e incerteza do processo.

# 28. Cenário conservador

Deve representar um valor que continue plausível mesmo com condições menos favoráveis. Deve considerar comparáveis mais prudentes, menor poder de negociação e incerteza relevante.

# 29. Cenário base

Representa a melhor estimativa central sustentada pelas evidências disponíveis.

# 30. Cenário otimista

Representa uma condição favorável, mas plausível. Não deve ser usado para justificar sozinho uma compra.

# 31. Confiança da estimativa


| Nível | Características |
|---|---|
| Muito alta | Muitos comparáveis fortes, recentes e consistentes. |
| Alta | Boa base e baixa dispersão. |
| Média | Dados suficientes, mas com diferenças. |
| Baixa | Poucos comparáveis, dispersão ou dados antigos. |
| Insuficiente | Não há base confiável. |


# 32. Componentes da confiança


| Componente | Pergunta |
|---|---|
| Quantidade | Quantos comparáveis úteis existem? |
| Qualidade | São realmente semelhantes? |
| Atualidade | Os preços ainda representam o mercado? |
| Consistência | Os valores convergem? |
| Cobertura | Há mais de uma fonte/referência? |
| Dispersão | Os preços são muito diferentes? |
| Especialização | É um mercado comum ou muito específico? |


# 33. Dispersão

Quanto maior a dispersão entre comparáveis semelhantes, menor a confiança, salvo explicação clara.
Alta dispersão → menor confiança → maior margem exigida

# 34. Mercado com poucos comparáveis

Quando o mercado for pequeno, o Radar deve mudar de comportamento.
- ampliar gradualmente o raio
- relaxar características menos importantes
- manter características críticas
- aumentar incerteza
- reduzir confiança
- exigir margem maior
- marcar avaliação como condicional

# 35. Mercado sem comparáveis

Sem evidência suficiente, não deve haver valuation artificialmente preciso.

| Situação | Resultado |
|---|---|
| Nenhum comparável confiável | Valuation inconclusivo. |
| Poucos comparáveis fracos | Faixa ampla + baixa confiança. |
| Modelo externo confiável | Pode fornecer referência, mas manter incerteza. |
| Imóvel único | Análise especial e conservadora. |


# 36. Imóveis únicos

Exemplos: terrenos excepcionais, casas muito particulares, imóveis comerciais específicos. O Radar deve evitar comparar diretamente com imóveis comuns.
- valor do terreno
- potencial construtivo
- renda potencial
- uso permitido
- localização
- escassez
- comparáveis indiretos

# 37. Terrenos — valuation

O valuation de terreno deve privilegiar preço/m², localização, zoneamento e potencial.

| Fator | Importância |
|---|---|
| Localização | Muito alta |
| Área | Alta |
| Frente | Alta |
| Topografia | Alta |
| Zoneamento | Muito alta |
| Potencial construtivo | Muito alta |
| Infraestrutura | Alta |
| Preço/m² | Alta |


# 38. Casas e sobrados — valuation

Deve separar mentalmente o valor do terreno e o valor/estado da construção quando isso melhorar a análise.
- terreno
- construção
- idade
- padrão
- reforma
- vagas
- localização
- potencial do lote
- preço/m²

# 40. MCMV / baixa renda — valuation

O mercado deve ser segmentado por produto e público. Comparar diretamente com imóveis de padrão superior gera distorção.
- ticket

# 41. Valor de mercado x valor de venda rápida

São conceitos diferentes. Valor de mercado representa uma negociação normal. Valor de venda rápida representa um cenário de saída
mais urgente e pode exigir desconto. Para estratégias de revenda, o Radar deve considerar ambos.

| Conceito | Uso |
|---|---|
| Valor de mercado | Referência principal. |
| Valor de venda rápida | Teste de estresse da estratégia. |
| Valor de liquidação | Cenário extremo, não usar como base normal. |


# 42. Teste de estresse

Uma oportunidade forte deve continuar razoável quando o preço de saída for inferior ao valor base.

| Cenário | Exemplo |
|---|---|
| Mercado base | R$ 315k |
| Saída -5% | R$ 299,25k |
| Saída -10% | R$ 283,50k |
| Saída -15% | R$ 267,75k |

Se a tese quebra com pequena redução do preço de saída, a margem de segurança é baixa.

# 43. Relação entre valuation e score

O valuation alimenta desconto, margem e confiança. Portanto, um valuation com baixa confiança não pode produzir um score econômico tão alto quanto um valuation equivalente com evidência forte.

# 44. Exemplo completo — apartamento


| Indicador | Valor |
|---|---|
| Preço da oportunidade | R$ 220.000 |
| Comparáveis fortes | 8 |
| Mercado conservador | R$ 295.000 |
| Mercado base | R$ 315.000 |
| Mercado otimista | R$ 335.000 |
| Confiança | Alta |
| Custo total estimado | R$ 240.000 |
| Margem vs base | R$ 75.000 |
| Margem % vs base | 23,81% |
| Conclusão | Valuation favorável |


# 45. Exemplo — falsa oportunidade


| Indicador | Valor |
|---|---|
| Avaliação Caixa | R$ 350.000 |
| Preço | R$ 175.000 |
| Desconto Caixa | 50% |
| Mercado conservador | R$ 190.000 |
| Mercado base | R$ 205.000 |
| Custos | R$ 25.000 |
| Custo total | R$ 200.000 |
| Margem vs base | R$ 5.000 |
| Conclusão | Não é oportunidade econômica |


# 46. Exemplo — valuation incerto


| Indicador | Valor |
|---|---|
| Preço | R$ 180.000 |
| Comparáveis | 2 fracos |
| Faixa estimada | R$ 190k–270k |
| Confiança | Baixa |
| Custos | R$ 25.000 |
| Conclusão | Não classificar como excelente; exigir análise adicional |


# 47. Regra de decisão com faixa


| Situação | Interpretação |
|---|---|
| Custo abaixo do cenário conservador | Muito forte, se risco/liquidez forem bons. |
| Custo entre conservador e base | Boa oportunidade potencial. |
| Custo próximo ao base | Margem pequena; depende da estratégia. |
| Custo acima do base | Normalmente não é oportunidade de desconto. |
| Custo só abaixo do otimista | Evitar conclusão forte. |


# 48. Regra de margem exigida

A margem mínima deve variar conforme confiança e risco.

| Confiança / risco | Margem exigida |
|---|---|
| Alta confiança + baixo risco | Normal |
| Média confiança ou risco médio | Maior |
| Baixa confiança | Alta |
| Alta incerteza + risco alto | Muito alta ou rejeitar |
| Risco crítico | Rejeitar se hard rule |


# 49. Atualização do valuation

O valor estimado deve mudar quando houver evidência relevante.
- novos comparáveis
- mudança significativa de preços
- mudança de status
- alteração relevante do imóvel
- mudança de mercado
- nova informação sobre localização
- mudança de aluguel para estratégia de renda

# 50. Histórico do valuation


| Data | Mercado base | Confiança | Motivo |
|---|---|---|---|
| 01/07 | R$ 300k | Alta | 8 comparáveis |
| 01/08 | R$ 307k | Alta | novos comparáveis |
| 01/09 | R$ 315k | Alta | mercado local atualizado |


# 51. Revisão por evento

Toda mudança material deve gerar nova avaliação, preservando a anterior. Nunca sobrescrever a história.

# 52. Detecção de anomalia

Depois do valuation, o Radar deve calcular se o preço do imóvel está fora do comportamento esperado.
Preço observado muito abaixo da faixa esperada → possível anomalia → investigar antes de recomendar

# 53. Anomalia não é oportunidade automaticamente

Uma anomalia pode significar oportunidade ou problema oculto.

| Anomalia | Possível explicação |
|---|---|
| Preço muito baixo | Urgência real |
| Preço muito baixo | Imóvel deteriorado |
| Preço muito baixo | Problema jurídico |
| Preço muito baixo | Ocupação |
| Preço muito baixo | Erro de cadastro |
| Preço muito baixo | Mercado mal comparado |


# 54. Regra de investigação

- Detectar preço fora do padrão.
- Verificar comparáveis.
- Verificar características do imóvel.
- Verificar custos.
- Verificar riscos conhecidos.
- Verificar se a diferença é justificável.
- Somente então elevar a prioridade.

# 55. Valuation e aluguel

Aluguel é uma validação adicional, principalmente para estratégia de renda. Um imóvel pode estar barato para compra, mas ter aluguel fraco; também pode ter desconto moderado e excelente renda.

| Indicador | Uso |
|---|---|
| Valor de mercado | Principal para desconto. |
| Aluguel | Principal para renda. |
| Yield | Principal para retorno. |
| Liquidez | Principal para saída. |
| Valorização | Complementar. |


# 56. Valuation e custo de oportunidade

A existência de desconto não basta se houver alternativa claramente superior. O Radar deve permitir comparar oportunidades entre si.

# 57. Erros que o valuation deve evitar

- usar avaliação da Caixa como valor de mercado automaticamente
- usar somente um comparável
- misturar tipologias
- misturar padrões
- misturar áreas diferentes
- ignorar condomínio
- ignorar reforma
- ignorar temporalidade
- manter outliers sem investigação
- tratar preço anunciado como transação
- dar precisão artificial
- ignorar baixa confiança
- misturar mercados muito diferentes

# 58. Governança do valuation

Toda metodologia deve ser calibrada com dados históricos.
- Selecionar amostra histórica.
- Calcular valuation como se fosse na data passada.
- Comparar com preços posteriores/transações disponíveis.
- Medir erro.
- Identificar segmentos onde funciona pior.
- Recalibrar ajustes.
- Revalidar.

# 59. Métricas de qualidade


| Métrica | Objetivo |
|---|---|
| Erro absoluto médio | Medir erro médio. |
| Erro percentual | Medir erro relativo. |
| Cobertura da faixa | Verificar se resultados caem na faixa prevista. |
| Confiança x erro | Validar se maior confiança realmente significa menor erro. |
| Erro por tipo | Apartamento/casa/terreno etc. |
| Erro por região | Identificar regiões difíceis. |
| Erro por faixa de preço | Identificar segmentos problemáticos. |


# 60. Regra de confiança calibrada

No futuro, confiança não deve ser apenas uma nota subjetiva. Deve refletir desempenho histórico do valuation naquele tipo de mercado.

# 63. Regra final de valuation

Não precisamos saber exatamente quanto vale. Precisamos saber, com confiança suficiente, se está barato o bastante.
O objetivo do Radar não é substituir uma avaliação formal de engenharia ou uma avaliação bancária. É produzir uma referência
de mercado suficientemente boa para selecionar oportunidades e decidir quais merecem due diligence aprofundada.

# 64. Integração com o Radar

O fluxo final será:
- Capturar preço da oportunidade.
- Estimar valor de mercado.
- Determinar confiança.
- Estimar custo econômico total.
- Calcular desconto líquido.
- Calcular margem.
- Testar cenário conservador.
- Avaliar liquidez e risco.
- Calcular score da estratégia.
- Classificar.
- Monitorar mudanças.

# 66. Conclusão

O valuation é o coração econômico do Radar. A principal função não é produzir um número bonito, mas construir uma estimativa

Uma oportunidade só deve ser considerada forte quando o preço e o custo econômico estiverem significativamente abaixo de uma
referência de mercado suficientemente confiável, levando em conta liquidez, risco e estratégia.

A partir deste modelo, o Radar poderá transformar milhares de ofertas da Caixa em uma lista pequena de oportunidades que realmente
merecem atenção. Posteriormente, o mesmo processo deverá funcionar para outros bancos e fontes sem alterar o conceito econômico.
